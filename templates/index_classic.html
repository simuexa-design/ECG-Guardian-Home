      📖 Academic Research Methodology & Mathematical Formulations

      1. SE-ResNet-1D Architecture & Channel Attention

      The classification backbone leverages a 1-dimensional deep residual neural network augmented with Squeeze-and-Excitation (SE) channel recalibration. For a 1D feature map $\mathbf{u}_c \in \mathbb{R}^{L'}$:

      Global Avg Pooling: z_c = (1 / L') * Σ u_c(t)
      Channel Attention Gating: s = σ(W_2 • GELU(W_1 • z))
      Recalibrated Output: x̃_c = s_c • u_c

      2. Multi-Label Optimization via BCEWithLogitsLoss

      Because arrhythmias often co-occur (e.g. Atrial Fibrillation with Sinus Tachycardia), multi-label learning models class probabilities independently using the binary cross-entropy loss with logits:

      L_BCE = - (1 / C) * Σ [ y_c • log σ(logit_c) + (1 - y_c) • log(1 - σ(logit_c)) ]

      3. 1D Grad-CAM (Explainable AI Attribution)

      To compute the localized attribution score for class $c$, gradients of logit $y^c$ with respect to the final convolutional feature maps $A^k$ are pooled across time:

      Gradient Weights: α_k^c = (1 / L') * Σ (∂y^c / ∂A_k(t))
      Grad-CAM Heatmap: L_GradCAM^c(t) = ReLU( Σ_k α_k^c • A_k(t) )
      Interpolation: L_GradCAM^c is linearly upsampled to 2,500 samples & normalized to [0, 1].

      4. Pan-Tompkins Electrophysiological Telemetry

      The Pan-Tompkins algorithm isolates QRS complexes through 5 stages: 1) Bandpass filter (5–15 Hz), 2) Five-point derivative $y[n] = (1/8)(2x[n] + x[n-1] - x[n-3] - 2x[n-4])$, 3) Non-linear squaring $y[n]^2$, 4) Moving Window Integration (MWI, 150 ms window), and 5) Adaptive dual-thresholding with 200 ms refractory blanking.

      💡 Project Overview: Explainable Deep Learning for ECG

      In One Simple Sentence:

      This project uses Deep Learning (AI) to analyse ECG reports, detect heart rhythm problems, and show which parts of the ECG helped the AI identify them.

      1. Meaning of the Project

      This project uses Artificial Intelligence (AI) and Deep Learning to detect different heart rhythm problems (arrhythmias) using ECG signals.

      2. What is Deep Learning?

      Deep Learning is a type of Artificial Intelligence that learns patterns from large amounts of medical ECG data and makes predictions automatically.

      3. How Does This Project Work? (5 Steps)

      1. 📥 Input: Upload an ECG (heart signal) report in PDF, image scan (PNG/JPG), or CSV format.
      2. ⚙️ Processing: The system analyses and cleans the ECG signal, filtering out electrical noise and drift.
      3. 🧠 Detection: Deep Learning identifies abnormal heart rhythms with calculated probability scores.
      4. 🔄 Multi-Label: It can detect more than one heart problem at the same time (e.g. AFib co-occurring with Sinus Tachycardia).
      5. 🔍 Explanation: It highlights the important parts of the ECG graph (using 1D Grad-CAM heatmaps) that helped the AI make its prediction.

      4. Technologies Used

      Python 3.12: Backend language
      PyTorch: Deep learning framework
      SE-ResNet-1D: Neural network architecture
      1D Grad-CAM: Explainable AI attribution
      Pan-Tompkins: QRS detection & heart rate
      HTML5 & Canvas: Calibrated ECG monitor

      5. Main Aim

      To detect multiple heart rhythm problems from ECG signals and explain how the AI makes its predictions so healthcare professionals can understand and trust the results.

      ⚠️ Note: It is an academic college research project, not a replacement for a doctor's diagnosis.
